## Computer-018 · VPN 연결 전 · 중 · 끊은 뒤

평소 집 PC에서 여러 서비스를 실행해 두고, 아이폰에서 Tailscale로 접속해 에이전트와 웹 도구를 사용하고 있다. 아래 세 상태는 미션의 Windows 예시 화면으로 비교했다.

- 운영체제: Windows
- 연결 전: Wi-Fi 어댑터에 `192.168.x.x`가 보였다. 예시 출력에는 Tailscale 항목이 없었다.
- 연결 중: 앱에 `Connected`가 표시됐다. Wi-Fi 주소는 그대로였고, `Tailscale` 어댑터 아래에 `100.101.x.x`가 보였다.
- 연결을 끊은 뒤: 앱은 연결 해제 상태였다. Tailscale 어댑터 이름은 남았고, IPv4 주소 줄은 사라졌다. 대신 `미디어 연결 끊김`이 표시됐다.

## 생각해 볼 것

- Wi-Fi는 PC를 공유기와 로컬 네트워크에 연결할 때 쓰인다. VPN은 그 연결 위에 사설 통신 경로를 만든다. 회사 VPN은 외부에서 접근이 제한된 사내망에 접속할 때 쓰인다. 내가 쓰는 Tailscale도 VPN의 한 종류이고, 아이폰에서 집 PC의 서비스에 접속할 때 쓴다. 예시에서 Wi-Fi 주소는 `192.168`로, Tailscale 주소는 `100.101`로 시작했다.
