## 찾아보고 알게 된 것
1. 서버 관련 작업이 리눅스 명령어인 이유?
→ 장비가 리눅스 OS를 쓰니까

1-1. 리눅스 OS를 쓰는 이유?
→ 가볍고, 오픈소스이고, 재부팅 없이도 오래갈 수 있음

2. 깃허브 왜 씀?
→ 개발자는 주로 버전관리. 보안 담당자는 깃허브의 코드 스캔 + 의존성 스캔 기능, 취약점 정보 조회기능을 활용하고, 개발자에게 보안 경고를 보내 수정하게끔 유도하려고.

2. 깃배시 왜 씀?
→ 유닉스 도구 쓰려고. 대강 적으면, 리눅스 명령어 쓰려고 (리눅스가 유닉스를 씀)
