## Computer-014 Docker Desktop 윈도 설치 — 다음 Docker 실습 준비

### 한 일
- 설치 전 확인: Windows 11 Pro(빌드 26200), 메모리 15.9GB, 가상화 동작 중(조건 충족)
- Docker Desktop 4.100.1 을 winget 으로 설치했다 (Docker.DockerDesktop)
- WSL 이 없어서 관리자 권한으로 `wsl --install --no-distribution` 을 실행했다 (WSL 3.0.5.0)
- PC 를 재시작한 뒤 Docker Desktop 을 처음 켜고, 로그인은 건너뛰었다

### 확인한 결과
| 확인 | 결과 |
|---|---|
| Docker Desktop 창에 Engine running | ✔ 보였다 |
| docker --version | Docker version 29.9.3, build 5457199 |
| docker run hello-world | Hello from Docker! 가 나왔다 (처음이라 이미지를 내려받는 줄이 먼저 나옴) |
| docker ps -a | hello-world 줄이 보였다 (Exited (0)) |

### 페이지 안내와 다르게 한 점
- 설치 파일을 직접 내려받지 않고 winget 으로 설치했다.
- 그래서 모든 사용자용 경로(C:\Program Files\Docker)에 설치됐다. 페이지는 계정별 설치를 안내한다.
- WSL 은 `wsl --install` 대신 `--no-distribution` 을 붙여 리눅스 배포판 없이 설치했다.

### 새로 알게 된 점
- Docker 는 프로그램과 그 프로그램이 쓰는 실행 환경(파이썬 버전, 라이브러리 등)을 한 묶음으로 담아서 실행하는 도구다.
- 이미지는 만들어 둔 묶음이고, 컨테이너는 그 이미지를 실행한 것이다.
- 파이썬 서버와의 차이: 혼자 내 PC 에서 서버 하나만 돌리면 파이썬이 더 간단하다. 하지만 남에게 줘야 하거나, 파이썬이 아닌 프로그램(nginx 등)을 쓰거나, 여러 개를 따로 돌려야 하면 Docker 가 편하다.
- Docker 는 환경이 달라서 생기는 문제를 없애 주지만, 코드나 설정이 틀려서 생기는 문제는 못 막는다.
- 컨테이너는 밖과 분리돼 있어서, 서버를 쓰려면 포트 같은 것을 따로 연결해 줘야 한다.
